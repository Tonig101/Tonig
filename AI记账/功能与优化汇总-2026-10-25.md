### 命名与文案
| 项 | 说明 |

| 数据一致性修正 | 移除无糖艾玛后，气泡文案同步由「3 位省钱博主」改为「2 位」，与数据一致 |

### 架构与可维护
| 项 | 说明 |
|---|---|
| 单一数据源 `learningResources()` | 看板卡 / 聊天气泡 / 理财学院三处共用同一份资源，改链接只改一处 |

### 安全
| 项 | 说明 |
|---|---|
| 外链白名单 `safeHttpUrl()` | 只放行 http/https；`javascript:` / `data:` / `//host` 一律拦截（看板整卡隐藏、气泡走兜底文案） |

**修复后追加发现并修复的 1 项（用户截图反馈）**：简洁版省钱页二级页签整排渲染成空白块。
根因：`.sheet-body` 是「固定高度 + flex 列 + `overflow-y:auto`」，子项默认 `flex-shrink:1`
被压缩，页签行被压到 22px、`.atab` 只剩 18px，而 `.atab` 上下内边距各 9px 正好吃满高度
→ 文字内容盒高度为 0。修复：`body[data-ui-mode="simple"] #saveHubSheet .sheet-body > * { flex: 0 0 auto; }`，
页签高度 18px → **35px**，四个页签文字全部恢复。

## 五、已知限制（答辩前请留意）

1. **B 站镜像站 `snm0516.aisee.tv` 为第三方**：域名可能变动或限流，答辩前请实测能否播放，并准备本地下载版本兜底。`m.bilibili.com/space/<uid>` 会 302 到 `space.bilibili.com/<uid>`，属正常；**不要**改成 `www.bilibili.com/space/<uid>`（404）。
2. **红米鸡无链接**：只有复制指令，不是超链接，避免做成失效假链接。
3. **剪贴板在非 https / `file://` 下会降级**：建议答辩用 https 或 localhost 录制。
4. **简洁版刻意隐藏看板「理财课」卡**（`ui-full-only`），走聊天「理财课」chip 可达。
5. **省钱助手两套呈现**：简洁版是整页区块，完整版仍是弹层面板——这是刻意的，不是 bug。
6. 未覆盖：真机 `isTrusted` 原生指针、iOS Safari、B 站页面实际可播性、像素级视觉回归（无基线图）。
