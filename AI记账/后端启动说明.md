# AI 校园记账管家 · 启动说明（WorkBuddy 云服务版）

聊天智能与截屏识别，都通过 **WorkBuddy 云服务免密钥大模型 API** 实现：
前端（浏览器）直接用官方 SDK 调用云端，你**不需要申请或填写任何 API Key**。

## 它做了什么

- `index.html` 通过 CDN 加载官方 SDK `@tencent-ai/workbuddy-cloud-sdk`，并读取 `cloud-config.js`（仅含公开配置，无密钥）。
- `app.js`：发送消息时调用 `WorkBuddy 云服务对话模型`，渲染回复并执行 `add_bill` / `command` 动作；
  云服务不可用时自动回退到本地记账逻辑（开箱即用）。
- `ocr.js`：截屏记账调用 `WorkBuddy 云服务视觉模型`，把截图原样转录成文字，再交给本地规则做金额/分类解析。
- `server.py`：只负责**静态托管**前端页面（一键启动本地服务），云端调用由浏览器直连，不经过它。


3. 浏览器打开 <http://127.0.0.1:8000>

> ⚠️ **但请注意**：`127.0.0.1` / `file://` 不是云服务认可的来源，会被拒绝——
> 所以本地打开时「智能对话 / 截屏识别」会降级为**本地记账逻辑兜底**，弹窗会提示「云服务未连接」。

## 关于「截屏识别账单」（重要）

截图里往往只有商户名、金额、偶尔有日期，**稳定提取「分类 / 消费动机」很困难**，
因此视觉模型只负责把图片文字**原样转录**；真正的记账结构化解析（金额、商户、分类）
仍由前端本地规则完成，并保留「示例小票 / 手动录入」兜底。
请确认金额后再保存，不要把截图识别当作 100% 准确的自动记账。

## 省钱雷达的独立 API（可选，给大模型当工具用）

前端「省钱雷达」不需要后端起服务（`deals.js` 本地就能算日历和比价）。
如果你要演示「大模型调用我的 API」这条路径，再单独起这个服务：

```bash
python deals_api.py          # http://127.0.0.1:8010 ，接口文档 /docs
```

- 不配 `LLM_API_KEY` 也能用：`/api/deals/ask` 会走本地确定性回答（结论一样，只是没有润色）；
- 不配 `PRICE_API_URL` 就不会去抓任何电商页面，只做比价口径计算；
- 想接真实价格：在 `.env` 里配 `PRICE_API_URL` / `PRICE_API_KEY` / `PRICE_FIELD_MAP`，
  把官方接口的返回字段映射进来，比价引擎不用改。

常用接口：

```bash
curl "http://127.0.0.1:8010/api/deals/today?date=2026-10-24"
curl "http://127.0.0.1:8010/api/deals/calendar?days=14"
curl -X POST "http://127.0.0.1:8010/api/deals/compare" -H "Content-Type: application/json" \
  -d '{"item":"充电宝","budget":100,"offers":[
        {"platform":"淘宝","price":89,"spec":"10000mAh"},
        {"platform":"拼多多","price":79,"coupon":5,"spec":"10000mAh"},
        {"platform":"京东","price":99,"spec":"10000mAh","needQty":2}]}'
```

离线生成真实商家日历（不依赖任何服务）：

```bash
python deals_engine.py --today 2026-10-24 --days 56 --csv 真实商家日历.csv
python deals_engine.py --demo     # 三组比价口径自测（含"需买2件"陷阱）
```
