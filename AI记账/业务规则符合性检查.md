## 四、顺带修掉的一个 bug

`中午肯德基疯狂星期四 25` 这类「提到商家又带金额」的句子，原先会被优惠意图抢走，弹出 KFC 活动卡而不是记账。
现在：**句子里出现金额且不问价格/时间时，一律走记账**（业务规则 1 优先）。

```js
var hasAmount = /(\d+(\.\d+)?)\s*(元|块|块钱)?/.test(compact) &&
  !/(多少钱|贵吗|便宜吗|什么时候|哪天|几天|多久|划算吗|比价|哪家便宜)/.test(compact);
if (hasAmount) { return null; }   // 落到记账流程
```

```bash

python deals_engine.py --today 2026-10-25

python deals_engine.py --today 2026-10-25 --days 42 --csv 真实商家日历.csv
```
